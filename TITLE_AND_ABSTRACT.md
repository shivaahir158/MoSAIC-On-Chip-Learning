# Revised Title and Abstract

## Title

MoSAIC: Memory-Hierarchy-Aware DAG Scheduling for On-Chip MLP Training on NVIDIA GPUs

## Abstract

Training neural networks on GPUs involves thousands of dependent operations whose execution order, resource allocation, and data placement jointly determine performance and energy efficiency. Existing scheduling approaches treat these operations as abstract tasks, ignoring the GPU memory hierarchy that governs real execution cost. This paper presents MoSAIC, a scheduling framework for on-chip MLP training that decomposes matrix multiplications into configurable tiles, maps each tile operation to the GPU's register, shared memory, L2 cache, and global memory hierarchy, and constructs a dependency DAG where every tile multiplication, activation, loss, gradient, and weight update is a separately schedulable task. We profile each task for runtime, memory placement, power draw, and data transfer cost on NVIDIA Ada Lovelace GPUs. The CP-SAT constraint solver produces optimal schedules for small DAGs across multiple CUDA streams, which serve as supervision to recover compact, interpretable priority functions via Bayesian Optimization. A learned scheduler, MoSAIC, uses these priority functions with structural motif features (fork-join, fan-in, fan-out) to generalize to larger DAGs where exact solving is intractable. Experiments on a two-layer MLP with matrices of size 64x1024, 1024x512, and 512x10 show that flexible tiling (32x32 to 256x256) exposes a tradeoff between parallelism (up to 1040 concurrent tasks), GPU occupancy (up to 87%), and shared memory feasibility. Scaling from 1X to 3X matrix dimensions increases the DAG from 128 to 1901 tasks and the available parallelism from 10x to 81x, while total data movement grows from 14 MB to 272 MB. The MoSAIC scheduler achieves within 4.8% of the CP-SAT optimum and matches HEFT, while operating at O(V) runtime cost suitable for online scheduling. These results establish a foundation for architecture-aware, learned scheduling policies that can inform custom chip design for LLM training workloads.
